# Take 提示词写回合同

每个 Take 的原始导演信息保留不动，在其末尾附加：

```markdown
### 视频生成提示词｜即梦 Seedance 2 Fast（主用）
**状态**：READY_FOR_PROMPT / ASSET_BLOCKED / MODEL_FEASIBILITY_RISK
**生成时长**：<来自导演 Take；不可用时待确认>
**输入模式**：<文本/首帧/首尾帧/参考图；仅依据已核验模型能力>
**资产绑定**：<资产ID / 阶段 / 造型 / 版本或UNKNOWN>
**图片核验**：<IMAGE_VERIFIED / TEXT_ONLY / IMAGE_MISSING / UNKNOWN>

> <单段完整可执行中文提示词：主体与场景、开场状态、动作时序、运镜、终态、明确不可提前发生的事件>

**生成风险与备选**：<可行性、拆分建议、覆盖的源事件ID>

### 视频生成提示词｜MiniMax H3（备用，仅在触发时）
> <H3适配版本；保留同一导演与资产状态>
```

编译准则：
- 对象必须可辨认；按发生顺序写“谁→对谁→做什么→造成何种状态”。
- 镜头说明包括景别、摄影机方位、运动、画面主体、终态；与首尾帧保持同一空间轴线。
- 台词和可听见的声音按模型能力决定是否放进提示词；后期叠加 UI/字幕/BGM 不冒充模型可直接生成。
- 禁止提前显示后续剧情、误伤/误杀、瞬移、手中物品凭空替换；不要把否定词堆成无法理解的长串。
- 对于尚未设计的外观，只引用资产ID及待确认视觉需求，不写虚构的“已批准面容”。
