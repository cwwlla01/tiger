# 摄影机语义编译器 V2

输入：03权威镜头卡的 `camera_primary_id`、附加技法ID、轨迹、构图锚点、起止状态、时间段、轴线、风险、回退与素材状态。按导演的技法ID原样继承，不重新导演。技法词表见导演 Skill 的 `references/camera-technique-library.md`；如果不可读，依照03文字摄影规范编译，不猜测ID含义。

输出：每个生成 Take 一段具体、可复制的摄影动作自然语言：开场机位/主体画面位置 → 逐时间段摄影机运动与主体动作 → 对焦/时间处理 → 结束构图/动作状态 → 禁止变化。不要把ID、YAML管理字段或未核验控制参数塞进最终复制块。04仅写静态瞬间，不把运镜误写成静态帧；05写动态轨迹。

门禁：CAM-22 要同时描述机位移动、反向变焦与主体尺寸锁定；CAM-12 要有环绕方向、机高变化与主体锚点；CAM-21 要有起止方向与转场边界；CAM-31 要区分冻结时间、多视角运动与后期；CAM-29 要区分时间处理与物理镜头运动。无法实现时保留导演意图并标注 `CAMERA_EXECUTION_BLOCKED`，建议拆 Take/3D/后期或退回导演，绝不擅自改成普通推拉镜。

同一 Take 内多次切机位或连续跨轴，先核验实际模型能力，否则生成子段并保持源事件、母 Take ID 和剪辑意图。未知型号参数标记 UNKNOWN，不声称模型可精确执行焦距、运动曲线或子弹时间。
