# V2.2 视觉提示词编译

读取03权威镜头视觉卡及系列/场景视觉圣经；不得自行更换主光方向、角色材质、摄影机技法、人物身份、场景天气或构图目标。04只编译单帧可见构图、光影、材质、景深和静态环境状态；05按时间顺序编译摄影机轨迹、人物动作、光影变化、动态物理、天气与声音节点。镜头从阴影进入光区时描述随位置变化的受光过程，避免静态灯光描述与运动冲突。

## 优先级与精简
顺序：01事实/02身份资产/03镜头意图 > 系列/场景视觉基准 > 单镜头必要差异 > 模型适配。最终可复制提示词只放该模型需要的具体可见可听描述，不机械复述10类术语。每Take最多突出1项主构图规则、1项主氛围和必要光源，其他继承基准。仅在模型入口支持时使用独立negative字段；否则用少量具体正向约束和必要禁止项，不堆砌泛化负面词。

## 模型能力边界
焦距数字为等效视觉参考，不保证光学物理精确执行；光追、GI、路径追踪等词不保证真实渲染管线。未知音频、负面词、帧控制、时长能力标UNKNOWN并查证；不可假定所有视频模型静音。身份一致性优先靠已核验参考资产和镜头拆分；“无畸形”文本不构成保证。光影闪烁、色溢、肢体错误属于生成后审核项。

## 失败回退
构图冲突→保留03主构图并退回确认；复杂物理/浓雾遮挡→提出分Take或后期方案；光学效果不可控→提出视觉近似并标注导演批准需求。不得静默更改03。
