# 视频提示词全要素
每段保留 EP/SC/SH/T/subtake 和源事件。制作卡依次包含：任务模式T2V/I2V/R2V/编辑/延长；具体型号及证据；已核验主体身份/服装/怪物个体/伤痕/道具持有；场景空间锚点及左右前后；起始姿态；时间顺序动作与受力接触点；机位高度/景别/视角/运动/焦点；光源材质与3D国漫CG风格；现场声音与对白（源剧本原文）；终止状态；2-5项关键禁改；生成时长与剪辑时长分别记录；后期边界；可核验验收条件与失败重切方案。
实际提交模型的提示词用自然语言写可见可听内容，不直接塞内部ID和审核标签；复杂物理动作拆成单主因果链的A/B/C子段。模型能力未知时不得称可直接投喂。
