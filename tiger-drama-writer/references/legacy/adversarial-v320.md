# V3.20 pattern adversaries and release gates

Run the old structure and anti-padding auditors and all unit fixtures. The templated-dialogue warning detects high nine-character shingle overlap even when exact utterances differ; repeated-scene-action warning detects heavily recycled narrative action. Both are heuristic review triggers, not automated artistic failures. Test on real cross-genre original drafts as negative controls; disclose false alarms.

Manual release review still checks distinct character goals, irreversible state change, resource provenance, power-fantasy payoffs, and stage-read runtime. Never equate no flags with "finished" or "no obvious problems". Require red-team fixtures including exact padding, synonym padding, and thin scenes.
