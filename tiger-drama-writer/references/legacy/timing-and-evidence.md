# 时长与证据流程

区分目标时长、保守代理估算、作者预算和实际演出时长。未知的实际时长保持为 null。旧版代理估算假定中文对白语速为每分钟180–300字，动作使用固定时长范围。此估算不适用于其他语言；应直接估算相应对白时长并说明限制。

目标时长为90–150秒时，在动笔前先预算各场景。每项动作都要识别独立操作、可与对白重叠的部分、可读的界面信息、停顿和刻意跳过的时间。购买存储设备、回家、复制文件并检查结果，不会因为一段话就能保证在四秒内完成。应拆分节拍或明确标示省略；不要规定摄影镜头。

完成初稿后，将实际对白和独立动作与原预算比较。不同内容的剧集使用相同预算，并不能证明它们实际时长相同。如果一集内容稀少，只有通过不自然地放慢对白或安排未解释的等待才能填满对白预算，就应标记该预算缺乏支持；保留它作为原计划，另行记录任何修订估算。不要把额外动作时间算入对白预算，也不要仅因为代理时长与目标重叠就声称达到最低目标。

如果整个代理估算范围都低于用户要求的下限，就对照场景预算检查剧本中实际动作、明确停顿和对白。只计算文本实际呈现且确实占用时间的事件。钓鱼片段不会因为真实钓鱼可能需要等待，就自动得到一分钟未说明的等待时长；省略号或“后来”都不算屏幕时间。代理估算是筛查值，不是最终结论：具体、可演的动作可能合理占据代理估算未计入的时长，但不能把明显且未解释的缺口、想象中的表演余量或照抄的写前预算当作证据。如果用户询问当前文本是否支持目标时长，而正文事件并不支持，就应直说不支持；不能用尚未写入的等待或慢速表演来称“有可能”。仅在获准后修订情节。这不等于场景在物理上不可能延长。不要为了凑数字加入填充内容或拖慢表达；真实计时前，实际时长仍应保持未知。

需要详细计划时，可使用 `verify_timing_plan.py SCRIPT PLAN --output REPORT`。它检查哈希、场景、对白时长分配、动作锚点和算术，不检查物理可行性。复合动作段落应人工检查。结构上有效的130秒计划在实际演出时仍可能超时。

仅当用户提供真实演出证据及其绑定计划时，才使用 `audit_rehearsal.py`。缺少真实证据时，使用未演出模板；不得模拟人物或时码。只有在确实收集到回答时才使用声线/情绪评审表。调用工具前阅读其 Schema/模板。外部检查不能阻止完成已授权的文本写作请求。

如果代理估算的下限超过目标，应保留失败结果并在获准时修订：删掉重复解释、让选择具体呈现、重叠兼容动作、保留阻力与代价，然后重新计算。如果只有上限超出，不要自动删减场景。绝不要把代理估算或声明的计划称为实测时长。
