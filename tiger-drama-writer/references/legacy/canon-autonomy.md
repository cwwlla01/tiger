# 正典优先的自主故事推理

1. 在内部事实清单中逐字提取用户陈述。分类为 LOCKED_USER（明确事件、规则、动机、命运）、DERIVED（基于前提作出的严格推导）、PROPOSED（创作新增内容）。用户后续更正优先于助手更早的创作。
2. 建立最简历史时间线：发生了什么、何时发生、谁采取了行动、改变了什么、当前阵营/资源如何形成。把含糊内容记为未知；仅在无害时推断。若故事说一场事故发生在末日之前却没有给出日期，就标记为时间未指定，不要擅自断言日期。
3. 为8–20个主要事件绘制因果图：行动者 + 目标 → 决策 → 后果 → 反制。对于关键物件，注明来源、位置、保管/持有者和约束。反派必须拥有独立于主人公的目标和不可妥协的价值观。
4. 审查力量体系：基础属性与实际属性、获得/消耗的点数、永久与暂时损伤、阈值与代价、资源可用性、等级与属性。确保不存在无解释的提升或方便剧情的能力。
5. 区分创作室掌握的真相与屏幕上揭晓的信息。锁定的谜底应保存在内部设定圣经中；通过公平线索铺垫，但不要在开场新闻蒙太奇里揭晓一切。
6. 预检阻断项：与 LOCKED_USER 矛盾、地理/时间线不可能、人物知识缺少铺垫、账目不平、对手无故违背动机，以及缺少铺垫支撑的最终结果。写作前修复一到两轮；只报告真实且仍未解决的阻断项。
7. 除非用户明确要求讨论，或某个选择确实不可或缺，否则不要让用户替你选择反派类型、整季故事弧或结局。

回归示例：用户说五道门来自不同世界；骷髅门释放了三只生物；太阳教首领曾与它们交战；一柄长期受供奉、带有太阳标记的剑被留在骷髅门；某蜂巢实体在妻女遭遇车祸身亡后接受深渊力量以复活她们，但复活后只是扭曲残骸。以上全部记为 LOCKED_USER。不要编造蜂巢实体是三只生物之一、它只追求泛化的进化，或剑的来历未知。除非有证据支持，事故的确切日期仍保持未知。
