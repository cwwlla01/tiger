# V3.39 — Scene-level production checkpoint

Do not generate a five-episode batch in one compressed prose burst. For every scene, write the *whole* playable action/dialogue before moving to the next scene. Maintain a working episode file with `## EPnn｜title` and `### n-k place` headings. After each scene, if executable tools exist, run `python scripts/scene_checkpoint.py path.md --episode N --scene K`. If `NEEDS_REALIZATION`, inspect the actual deficient scene and add a distinct causal exchange or concrete action; don't repeat dialogue to meet numbers. If code tools are unavailable, apply the same editorial inspection manually. A clean static checkpoint must still pass a human scene test: (1) who wants what immediately, (2) who resists, (3) the two different attempts, (4) an actual witnessed cost, (5) an after-state with a causal handoff. Record missing beat labels privately, write the scene, and check again.

Do not treat a beat checklist or arbitrary word minimum as a screenplay. Freeze the first complete authored episode **before repair**; append revised scene text only to a separate version. Full batch acceptance is after all episode/scene checkpoints, continuity and genre checks and a human read. Automated checks are diagnostic only. If your output channel cannot hold a full batch, write episode files sequentially or report genuinely incomplete coverage instead of shrinking scenes.

Regression history: V3.38 fresh three-episode emotional test had 0/3 episodes meeting both episode and scene checks. The new script identifies weak scenes and provides a precise stop/go *screening* signal; it does not establish that the new drafting method improves model quality until new untouched first drafts pass.
