# Episode-first realization loop

1. Freeze a terse story/state capsule. Mark confirmed facts and suggestions separately.
2. Draft EP01 as full SC01–SCn with real stageable conflict, back-and-forth dialogue, counterplay, result and new state. The next episode does not exist yet.
3. Save an **unchanged first-pass** file (or immutable section). Audit the actual episode. Independently ask: whose option changed, by what action? What physically happened? What was lost? Did information suddenly become certainty?
4. If it fails, repair this episode before drafting the next, but keep metrics of the unmodified pass distinct from any rework.
5. Write EP02 using the signed-off handoff. Repeat. A batch is an ordered set of validated episodes, not an outline expanded under an aggregate length budget.
6. Archive episodes, audit JSON, weaknesses and untimed status. Never infer 90–150s from characters. A real timed performance is a separate acceptance gate.

## Example failure avoided

Bad: 'She tells the guard the pump is unsafe; he agrees and gives her water.'

Dramatized: guard withholds contracted water; pump pressure climbs; protagonist requests evacuation, tries valve, hurts hand, guard tries to re-open; she pins the valve, demands signed repair log; guard yields one liter not two, and a new posted policy targets her next episode. No new water is manufactured; only a debt is partly paid.
