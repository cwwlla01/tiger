1. Freeze a single creative prompt, episode count, locked canon, desired duration, and external context. Save before/after generator instructions and unedited outputs. If unable to execute both versions independently in equivalent conditions, mark comparison **not controlled**.
2. Audit each raw episode using identical `scripts/audit_script_batch.py` logic; report scenes, dialogue turns, spoken Chinese characters, body Chinese characters, and warnings without erasing failed attempts.
3. Run distinct human-editor checks for active protagonist choice, antagonist/constraint response, evidence before inference, state transitions, conflict-mode repetition, emotion and genre promise. Provide scene quotations/evidence rather than a single composite score.
4. A two-episode sample is only a pilot, never a cross-genre or stable full-season acceptance. A static pass says structurally reviewable, never production-ready. Read-through duration is UNTIMED unless timed.
5. A strong intervention is writing each complete scene sequentially with opening pressure, specific failed or costly action, counterplay, irreversible change, and live dialogue, not adding more planning fields or dialogue-padding. Preserve original drafts in artifact files.
