# V3.1 五集成品生产门槛：先剧本，后报告

## 产出与验收顺序

1. 从同一权威项目版本选择连续五集，冻结用户锁定设定和能力/物资/人员起点。若是一般独立创作，不必硬套《深红》的具体数字。
2. 为五集分别明确：当集外在目标、对手反制、主角主动策略、可见结果、成本、下一集承接；至少一个跨集冲突在五集内有物质或关系上的真正兑现。不能用五个新悬念替代一个旧兑现。
3. **先交完整动作和对白场景，再进行评价**。每集必须包含连续可演场景、人物能说出的完整对白、转折行为与集末变化。没有剧本文件不许声称“完成五集”。
4. 运行 `python scripts/audit_script_batch.py <script.md> --output audit.json`。脚本只统计集号、场景、对白轮次、对白汉字量、正文汉字量、占位词；阈值仅是复核信号，不是通过证书。
5. 人工复核每集：有无假冲突、先知信息、反派配合送资源、无证据倒戈、属性点双花、角色伤势失踪；替最严重的问题**直接重写文本**（最多两轮）。局部重写必须进行后续影响审查。
6. 标注每集的 `OUTLINE / SCENE_DRAFT / FULL_SCRIPT / TIMED`：只有实际朗读或排演计时才称 TIMED；未经计时，字数多少都只能标 UNTIMED。对于无硬性占位符、因果与完整对白都合格但仍需拍摄前检查的文本，可称 `FULL_SCRIPT 候选` 而非投产成品。
7. 随剧本交付状态变化（角色、伤势、位置、资源、能力基础值及剩余点、伏笔回收/欠账）和下一批续写入口；把用户设定与 AI 提议角色区分开。

## 反作弊

- 不要用标题/长段剧情说明凑“正文篇幅”；审查说话轮次和真正的可演动作。
- 不要为了满足统计阈值制造无意义对白或多余场景；低值触发审查而非机械填充。
- 不要把正文汉字数换算为宣称的2–3分钟；在无表演计时情况下只给带不确定性的编辑估计。
- 在连续5集里，既要有阶段爽点也要有成长成本；末集必须产生不可逆状态变化。
