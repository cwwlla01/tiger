# Single episode scene-level acceptance (V2.3)

When evaluating a single episode, distinguish STORY BEATS, SCENE DRAFT, FULL SCRIPT (dialogue and playable actions complete), and TIMED (an actual recorded/read-through duration was measured). Never use character counts or nominal minutes as proof of runtime.

A complete episode must have: an intelligible starting predicament inherited from preceding episode; ≥2 causally connected dramatic turns rather than exposition; protagonist-specific choice with observable consequence; at least one payoff or genuine gain (tactical, emotional, informational, relational); an attributable cost; a closing twist earned by prior facts; natural dialogue and actions in numbered scene headers. Keep continuity ledger and list all proposed new names, rules, props as provisional until user canon acceptance.

For serial upgrade dramas, if an episode contains capture/defeat and the primary payoff is deferred, record a payoff debt and set concrete payoff deadline within the next 1–3 episodes. Reject an additional defeat-only episode if it does not materially change leverage. Verify upgrade math line by line; no stat changes without explicit source and spending. Limit scene length by dramatic necessity, not arbitrary padding. For each dialogue exchange ask: could it be deleted without changing tactical/emotional state? If yes, remove or rewrite.

Before delivery review failure evidence, rewrite the affected beats, then re-check all scene-to-scene causality and character knowledge. Report estimated vs measured runtime separately. Script quality is editorial judgment and cannot be equated with audience retention.
