# Downstream revision propagation

After changing a scene, create a state delta with: alive/dead/captive, physical locations, injuries/contamination, material inventory and provenance, protagonist power ledger, each person's learned facts, relationships/obligations, newly resolved hooks. Compare the delta to the first appearance of each fact in all later episodes within the affected arc.

1. **Duplicate-event test:** mark each rescue, escape, kill, reveal and resource acquisition with an event ID. If the same event is replayed without an explicit new event, block integration. Prefer rewriting the downstream scene as the consequence (e.g. after a person is rescued, stage intake, quarantine, testimony or medical care), not another rescue.
2. **Seam test:** for adjacent episodes compare exact last-scene state against next first-scene state. Carry over unresolved injuries and antagonists' agency. Point to scene IDs; an editorial assurance without evidence fails.
3. **Knowledge test:** identify the precise scene that taught each character key information. A clue must not automatically become certainty. Distinguish hypothesis, observed evidence and verified conclusion.
4. **Resource test:** water, ammunition, people, food and progression points do not appear from events that merely protect or redirect resources. Track net change and available quantities with uncertainty when unknown.
5. **Downstream closure:** when revising episode N, audit N+1, later arc hinges, and future scene references; rewrite contradictory scenes immediately. Record affected downstream drafts and notify if a future episode file is unavailable.
6. **Acceptance:** only claim "integrated" when replacement screenplay text exists, the timeline has no duplicated event, and the state delta is exported. Timed runtime needs actual read-through; screenplay length heuristics are not proof.

Minimal repair example: Episode 19 already frees Person A from a trapped vehicle. Episode 20 must **not** again cut open the vehicle to free Person A. Instead isolate the rescued person, deal with disputed entry, extract an uncertain clue, and show the settlement's cost of taking the risk.
