# V3.22 生成与验收双轨标准

1. 生成每集完整正文后，保留原始首稿；先检查角色实际目标、连续的行动与反制、可见代价、不可逆变化和与下一集交接。不要把分集梗概放在场景标题下充当正文。
2. 同时运行 `scripts/audit_script_batch.py` 与 `scripts/audit_adversarial.py`。`UNWRITTEN_PLACEHOLDER_BLOCKER` 是交付阻断项：出现任何明确待补/略写占位内容，都不能称为完整剧本。修复原文后再跑检查，不可以简单删除占位符而不补写缺失的动作与对白。
3. 其他统计指标仍是风险提示；仅有场景、对白、字数达标不足以证明故事好看。必须人工检查：主角行动是否有动机、对手是否合理、资源与能力是否真实有源、情绪回报是否兑现、同类型机制是否重复。
4. 保留初稿通过率、修订后通过率、未通过项、已修复场景以及尚未测量的演出时长，禁止宣称仅凭文本就达到2–3分钟。
5. 用故障样本（占位、灌水、无效会议）和正常行动样本回归，防止把质量检查器变成一味增加字数的工具。
