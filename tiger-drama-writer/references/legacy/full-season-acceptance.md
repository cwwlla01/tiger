# Full-season one-click acceptance

Run these tests on the finished **scene-level** text, not the beat outline.

1. **Coverage**: each numbered episode contains headings, playable action, attributed dialogue, ending; count exact coverage.
2. **Time**: estimate action/lines/holds per scene; do not assert actual runtime until audio read-through and rendered video are measured. Flag dialogue-light episodes.
3. **Causal chain**: for each episode show setup, choice, effect, and carryover.
4. **Clue ledger**: sender/identity, object origins, who-knows-what and time-of-arrival must be reconciled.
5. **Genre promise**: suspense gets fair clues and consequential discoveries, romance gets voluntary relationship changes, revenge gets earned gains and costs.
6. **AI constraints**: visual repeat, weather/wardrobe consistency, object continuity, crowd effects, lip-sync complexity and risky effects.
7. **Evidence**: self-scoring is editorial and must mention actual problematic scenes; fix blockers or mark non-production-ready.
8. **Output**: bundle complete screenplay, production assumptions, fail/pass table and unresolved issues.
