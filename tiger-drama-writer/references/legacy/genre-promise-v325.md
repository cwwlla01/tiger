# V3.25 central genre promise: an on-page result, not a label

Before each episode, note what the audience came to watch (e.g., upgrade competence, romantic relationship choice, verified mystery breakthrough) and one **specific, non-repeatable visible payoff**. Separate a tactical payoff from a system upgrade: using previously-earned power is valid; a new numerical award requires a traceable source and explicit arithmetic.

For upgrade fiction, keep a four-column ledger: **source/confirmed balance → expenditure or trained capability → visible obstacle that requires the capability → victory and cost**. Never promise that a stat improved unless source, amount and allocation are on page. If no new pickup is justified, stage a previously-established capability as a decisive tactical solution, with its limitation and a consequential price. At least one scene per short arc must make that genre promise visible. An administrative victory can support but cannot always substitute for the genre's promised exceptional ability.

For mystery, payoff means a verified evidence-state shift, not an unearned culprit revelation. For romance, payoff can be a concrete boundary/choice or relational shift, not manufactured misunderstandings.

**Draft before checking:** every episode has a genre-contract line (private planning), an exact before/after state, a paid cost, and an end trigger. Review after full script: highlight evidence in the text for each. If evidence is absent, revise an existing action scene; do not append an exposition speech or fabricate a new system reward.

**Regression discipline:** archive the raw first-pass, any revisions, and the fresh continuation independently. Run script auditor, adversarial auditor and batch release gate. Report separate machine screening and manual genre-contract inspection, with untested timing clearly marked. A single repaired sample cannot establish cross-genre or long-range reliability.
