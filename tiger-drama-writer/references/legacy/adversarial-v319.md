# V3.19 anti-gaming regression protocol

1. Save unedited first-pass text and the latest repaired candidate as distinct files.
2. Run structural coverage auditor and the adversarial auditor on both.
3. Examine any automated false negative by creating an archived minimal counterexample. Historical regression: repetitive dialogue of identical wording and sufficient gross text cleared a structure-only check.
4. For each episode, conduct manual blocking review: does every scene contain actual counteraction and a visible state change; is a deduction supported by evidence; do powers and resource gains have verified provenance; does the next episode inherit injuries and facts; are there distinct emotion and payoff mechanisms across episodes?
5. Any blocker requires an actual script correction followed by adjacent-episode checking. Red/yellow reports are preferable to unearned “pass.”
6. An automatic PASS means only **screening checks found no issue**; never call it a read-through, production certification, audience retention, or proof of genre generality.
7. Audit test fixtures on every relevant release; report how many adversarial cases were caught and list untested classes.
