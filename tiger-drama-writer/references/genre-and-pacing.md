# 多类型叙事引擎与单集节奏手册

将以下内容作为创作与审稿时的专业判断基准，而非死板的数字配额。

## 1. 类型承诺校准（避免所有题材都写成同一种爽文）

| 故事引擎 | 场景中真正要发生的变化 | 应兑现的观众体验 | 需警惕的虚假替代品 |
| --- | --- | --- | --- |
| 小人物逆袭 / 复仇 | 主角运用筹码；对手调整策略；资源、地位或控制权实际易手 | 清晰且有代价的局势逆转 | 对手仍握全部权力，主角只靠嘴炮或旁人夸奖“有风度” |
| 爱情 / 甜虐 | 吸引力与具体恐惧/义务冲突；选择改变亲密度与脆弱边界 | 通过行为与抉择体现化学反应 | 两位同事也能原样照搬的礼貌对话或强行壁咚 |
| 悬疑 / 推理 | 异常引出假设和鉴别行动；新证据改变可信对象或行动方向 | 基于公平线索的推理反转 | 结尾演讲凭空揭晓此前画面从未出现过的关键证据 |
| 喜剧 | 明确欲望、错误策略或不相容需求引发连锁失控 | 符合人物性格的铺垫与反转 | 人物礼貌办完琐事，只靠插入段子或谐音梗搞笑 |
| 家庭 / 伦理 | 忠诚冲突转化为要付出代价的行动或实际待遇变化 | 有铺垫的情绪转折或关系破裂 | 全员坐下互相解释主题、握手言和，但行为毫无改变 |
| 奇幻 / 规则流 | 能力使用受明确规则与代价约束，升级带来新问题 | 规则一致性下的智取或代价感 | 凭空获得新技能破局，且上一集的限制被悄悄遗忘 |

**混合类型原则**：尊重混合题材，选定一个主承诺；不要把温柔爱情强行塞入打脸羞辱桥段，也不要把悬疑的推理空间用巧合抹平。

## 2. 单集微观节奏与成稿质感

- **开场 0–10%（前 3 拍入戏）**：前 3 个动作/对白节拍内必须抛出异常行为、直接冲突或信息错位，不写慢热寒暄；连载集直接承接上集后果，不重复复述前情。
- **推进 10–30%**：确立当前局部目标与实打实的阻碍，通过可演冲突亮明利害，不做大段背景播报。
- **中段 30–75%**：阻力升级；第一次尝试受挫后，人物被迫付出更高筹码、调整策略或做出两难取舍；连载中应适时由主角自身执念或判断盲区触发波折。
- **收尾 75–100%（翻面卡点）**：兑现至少一项当前承诺的张力，给出可见的阶段性状态变化；集末钩子优先设计“看似即将达成或稳住局势，却在最后一件可见道具/动作上翻面”的落差，少用纯口头狠话黑屏。
- **台词质感约束**：拒绝“端水式说明文对白”（角色把背景和心理直接讲给观众听）。能用 `△` 动作推拉表达的拒绝、警惕或试探，不重复写成解释台词；竖屏/快节奏剧集单句对白保持口语短句。

## 3. 反注水与因果核验

- **删集测试**：如果抽掉这一集不影响后续人物关系、信息量或资源状态，说明该集无效，应合并或重写。
- **反套路重复检查**：若连续 2–3 集都在用“偷听对话”“匿名举报信/神秘录音”“反派无脑嘲讽”推动冲突，必须替换为物理行动、道德两难或阵营反制。
- **行动促成原则**：写决定性转折前自问“若主角什么都不做，结果会怎样？”。偶然事件可以制造麻烦，但不应替主角解决核心难题。
- **利害与代价相称**：小故事可以只有小利害（如丢掉约定、方案被否、当众出丑），不要为凑“牺牲感”强行制造车祸、绝症或非理性决裂。
- **完成态核验**：严格区分 `意图 → 准备 → 执行 → 交付 → 接受`。草稿写好不等于消息已发出；递出钥匙不等于已经打开门；口头认错不等于关系已修复。
