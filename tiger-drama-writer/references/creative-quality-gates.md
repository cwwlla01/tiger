# 剧本创作高质量对抗门禁 V2

## 使用时机
完成初稿或用户要求审核/优化时执行；普通问答不需要。只用当前授权的剧本及权威设定作为事实。先找反例，再确认优势；没有原文就不能宣称质量通过。

## 五个必须举证的门禁
1. **因果反证**：逐个关键逆转追问「删去此前铺垫，逆转是否仍发生？」若是，则逆转可能靠巧合/作者便利。标出证据所在场次、角色知情时点、行动成本；无证据判未通过。
2. **人物可替换反证**：交换两位主角的策略/关键台词；若动机、代价和结果完全不变，则人物辨识不足。只修改行动选择及其后果，不用口头禅补救。
3. **情绪可撤销反证**：删去一场牺牲/和解，后续选择是否不受影响？若不影响，则缺少不可撤销的关系变化；补充已有事件导致的可见行为后果，不凭空制造死亡。
4. **反派合理性反证**：对手是否为配合主角而突然失智、遗忘能力或忽略已知信息？若是，重建对手目标/限制/风险，不能只写「大意」。
5. **单集承诺反证**：观众在开头被承诺的具体问题，结尾是否给出可见阶段答案、真实代价和继续观看理由？只有悬念没有回报、只有胜利没有新状态，均需明确标注。

## 两轮定向修复
输出 `原文证据 → 缺陷根因 → 最小改动范围 → 修复后的可见证明 → 复审结果`。最多两轮定向修复；两轮仍失败，标为 unresolved 并说明阻断原因，禁止自称满分。纯审核任务不改稿。不能把新增伏笔悄悄追认为原文事实。

## 对抗性微案例（仅用于检验Skill，不是权威剧本）
- **伪智斗**：主角凭空知道敌人密码而获胜。预期：FAIL，缺少信息来源；不能用慢镜头掩盖。
- **伪群像**：配角只喊「小心」，主角完成全部行动。预期：检查配角是否需要自主目标；不强制增加戏份。
- **伪感动**：陌生角色牺牲后全员哭泣，后续行为不变。预期：FAIL，缺少关系铺垫或后果。
- **克制成功**：一场短促对话使角色承担真实风险，改变后续策略。预期：PASS，不因缺少大场面而降级。

## 边界
保留原剧本的剧集数、规则真相、死亡、人物关系和对白要求；对未授权新增的关键情节提出建议而不写入权威版本。不要将导演镜头、运镜、首尾帧当成剧本质量证据。


## V5 反转规则的可演证据与时点核验
- 对每个撤销、重投、计票、开锁、机关或特殊规则反转，分别记录：**规则首次在可演正文中出现的时点、允许操作的时间窗、实际触发时点、结果状态**。后台设定表、自审声明和结尾解释不能替代观众可见证据。
- 区分**实时预览**与**正式计票/结算**：若规则规定“计票前撤票”，正式计票后不得撤票；若先展示票数，须在前文明确该显示仅为预览，且尚未计票。
- 用反事实测试：删去作者附注，只看场景，观众是否能在反转前知道规则存在？若不能，标 `RULE_NOT_ON_PAGE` 并退回最小修复。
- 对秘密线索，至少保留一处反转前可见、但不直接泄底的物理或行为证据；结尾突然出现的新铭牌、新按钮不能独自承担伏笔。
