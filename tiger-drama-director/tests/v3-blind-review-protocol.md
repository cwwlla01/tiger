# V3 导演能力盲评协议

本协议评估真实导演效果，不是技能文本/字段结构测试。没有符合条件的输入、独立产物和评审时，不得宣称 V3 优于 V2。

## 冻结输入

- 以六类真实场次组成测试集：心理悬疑、双人对峙、情感爆发、动作高潮、群像生存、平静日常。使用用户提供或已获授权的冻结剧本；不得为补齐类别而伪造“真实案例”。
- 每个案例冻结同一版剧本、相关设定/资产、画幅/制作形态、输出范围和可用制作约束。记录路径、SHA-256、导演 Skill 版本与日期。
- 比较前需有可追溯的旧版基线和 V3 产物，由相同输入独立生成。历史文件只有在其实际版本可证实时才可作为 V2 基线；既有 EP001 草稿不能自动标成 V2.66 或 V2.69 结果。

## 匿名评审

把两版产物随机标为 A/B，隐藏 Skill 版本、作者与生成顺序。评审先独立写理由，再讨论；专业导演评审创作选择，目标观众评审实际感受。仅文稿评审标记 `TEXT_BLIND_REVIEW`，不能称成片盲审。

每个维度采用 1–5 级并附镜头/节拍证据；分数只用于组织判断，不替代书面结论：

### 艺术表现

- 戏剧/人物洞察是否具体而有依据；
- 观众注意力、信息差与情绪变化是否有效；
- 表演是否让心理和关系可见；
- 影像构想是否有辨识度且贴合作品，而非套路/炫技；
- 镜头节奏、停顿、爆发、揭示和兑现是否有呼吸；
- 是否能删掉重复镜头，导演选择是否令人信服。

### 制作与忠实度

- 剧情事实、因果、真实动作次序和用户锁定揭示是否保持；
- 空间、表演、资产/造型和镜间状态是否连续、可读；
- 复杂动作/镜头是否存在可执行的实现或保住体验的替代；
- 04/05 的新增信息、工时、生成失败/返工和成本（仅有真实数据时）。

## 成片复核与结论

- 从文本盲评选出代表性场次，以相同的生产条件制作两版代表性成片；锁定实际模型/入口、提示词、参考资产、生成设置、剪辑范围与失败次数。不可用一版实片对比另一版文字稿。
- 报告艺术偏好与制作代价是否同时改善、哪些场景出现回退、评审分歧和样本限制；不以单一总分覆盖关键缺陷。
- 只有独立产物和相应盲评/成片证据完整时，才得出比较结论。未完成成片时仅报告文稿层观察；无旧版基线时只报告 V3 可用性，不报告“胜过 V2”。
