# Cinematic Imagination｜电影化想象

创意竞争比较的是**观众会经历什么**，不是把同一镜头换成不同焦段。仅对关键场次启动，不让普通转场承担不必要的方案设计成本。

## 何时启动

通常适用于身份/规则揭示、人物关系或权力逆转、不可逆选择、动作高潮、情感兑现和集尾钩子。若一个直接清晰的拍法已显然合适，无需为了满足数量要求造出第二方案。

## 方案差异

可从以下维度组合出 2–3 个真正不同的方向：

- 观众站在哪一方、掌握多少信息；
- 体验核心是痛感、压抑、恐惧、愧疚、敬畏、荒诞或释然等何种冲突；
- 人物关系通过距离、同框/分离、遮挡、控制空间或反应归属如何显现；
- 主要画面/声音意象，以及揭示、等待、行动与反应如何排列。

每个方案在内部用简短结构描述：`体验目标 → 主要表演/空间/声画策略 → 观众所得 → 代价或风险`。不得只列“特写/推镜/正反打”等设备清单。

## 边界

创意可重构呈现，不得偷改剧本事实、角色认知、行动因果或已锁定揭示。若所有方案都无法保留关键戏剧功能，应指出缺口并提出需授权的改编，而不是伪造一个看似成立的镜头解法。
