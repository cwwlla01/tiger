# 03-专业导演分镜

## 标题区
- 剧集 / 来源：
- **权威输入版本：** 项目内权威剧本路径/文件名、版本；可取得时记录哈希。若附件与项目定稿有冲突，注明冲突和本稿采用版本；影响剧情事实时先解决，不静默择一。
- 导演模式：`DIRECTORIAL_RECONSTRUCTION`（若获准改编剧情，注明 `AUTHORIZED_ADAPTATION`）
- **项目制作基线：** 已确认的制作形态、画幅/宽高比、视觉风格；没有已确认值时，将导演提案标为未批准，不得默认成项目规格。
- 状态：`DRAFT / CANDIDATE / FROZEN` 等，如项目有状态规范则遵循项目规范。未实际完成的审核/生成不得写成通过；只有用户或项目授权流程明确冻结后才能标 `FROZEN`。
- 必要假设：仅列会影响分镜判断的假设
- **执行边界：** 说明本文件为本集独立导演执行母版；源文锚点用于追溯，不要求下游回读剧本。需要依赖的造型/空间定义须明确列出引用。
- **导演解析耗时：** 总耗时；剧本/资产读取、场次构思与审美决策、镜头执行、导演自审/修订（仅填实际测得值，无法测得写“未测”；不含等待用户答复、外部任务或工具排队）。此项不是集长、剪辑时长或 Take 生成时长。

## 场次导演方案
- **场次目标 / 阻力 / 转折**：
- **观众路径 / 视听构想**：开场看见或知道什么，关键揭示/误认/兑现何时发生；只写会影响镜头选择的导演解读。
- **空间与调度基准**：起止状态、人物/道具相对站位、行动路径、轴线/摄影机工作侧；只写该场共用信息，未核实位置标待核。

## 导演镜头卡

### SH01｜[镜头名]
- **观众体验（每个SH必填）**：本镜观众注意什么、知道/不知道什么，画面/声音触发后体验如何变化；必须对应具体内容，不用抽象情绪口号代替，也不能由场次目标代填。
- **时长**：剪辑目标只写一个秒数，如 `估算 4.0秒`（依据：动作/对白节拍）；或 `未锁`并写唯一待验证条件；用户/项目明确锁定时标 `锁定`。不写时长区间。
- **Take / 生成时长 / 帧策略**：列出承接本镜的 T ID 及关系（一镜一 Take、多 Take 拆解或共享连续 Take）；纯后期声画段标 `EDIT_AUDIO_ONLY`。用户指定目标模型时，每个 T 只写一个按当前界面核实的生成时长；未选型号/选项未核实时写待核，不列多项备选。剪辑时长和生成时长分开。为每个 T 标 `NONE / REFERENCE_ONLY / START / END / START_END / SEQUENTIAL_KEYFRAMES`，并说明需要的帧或不需帧的理由。仅在实际已存在时引用图片；待生成/缺失状态须如实写明。
- **镜头目的 / 源文依据与导演重构**：[观众要看见/理解/感受什么；源事件锚点；导演增补不得伪装成原文事实]
- **构图**：[画面里有什么、主体层次、位置、视线、遮挡]
- **摄影机**：[景别、机位/角度/高度、固定或运动及动机]
- **站位与调度**：[在场人物/道具相对位置、路径与接触关系]
- **表演节拍**：[可观察的反应、选择与情绪变化；不重复场次共用基准]
- **动作链**：分行编号写出 `起态 → 动作1/因果 → 动作2/因果（如有）→ 结果 → 终态`；多人接触、物件交接、转场或状态变化不得压成一句箭头概述。空间站位与时间动作分别说明。
- **台词/声音/后期**：[逐字列出台词、说话者、声源、谁能听见/看见、现场声/音效/音乐及必要字卡；无则写“无特殊声画”]
- **剪辑/连续性**：[入点、出点与衔接；只列本镜特有的继承项]
- **资产/造型/帧**：[相关 ID/状态；待生成首帧 ID；如使用多张现有输入参考图，按 `图序1、图序2...` 列文件名/ID和各自控制范围。缺失图片须标注，不伪称已有]
- **风险与回退（按需）**：[真实风险、验证条件、保住剧情结果的回退方式]

> 可将动作较长的镜头拆成若干生成单元，但不得让下游依靠上一集、上一镜、剧本或聊天记录补齐任一单元的起态、动作、台词、声画或终态。拆分单元应自带必要连续性状态。剪辑时长与生成时长分开；每个SH的剪辑目标使用一个具体秒数，不输出区间。生成渠道未知时不编造Take秒数；指定型号但界面选项未核实，写“待界面核实”且不列多项备选。估算镜头的合计只能作为估算，不能写成已锁集长。

## 制作交接与自审（按需）
- **交接缺口（仅有时写）：**跨镜继承、资产冲突、待验证条件及受影响镜头；写清回退方式/最小验证，不重复整份连续性表。
- **无剧本执行测试：**只读本文件及明确引用的资产/造型资料，能否还原在场人物、动作顺序、精确台词、声音/后期层、镜间衔接和终态？若不能，补齐03后再交付。
- **导演自审：**只记录发现并修复的具体问题，以及仍未解决且影响执行的事项；不输出内部候选评分或无关过程记录。

## 使用原则
- 必须满足 `SKILL.md` 中的最小交付字段；本模板是字段说明，不是要求逐项机械扩写。无特定连续性、资产、帧或风险时直接省略对应小节。
- 不要求套满模板：简单场次可缩短，复杂场次可补图或补表。
- 不按剧本文字行数切镜；每镜都应有独立而必要的戏剧/视觉职责。
- 不强制定镜头数、运镜、首尾帧或Take数；每镜必须写一个剪辑目标秒数及状态（锁定/估算/未锁），只有实际阻断因素才可未锁。
- 03 是导演方案，不是 04 图片提示词、05 视频提示词或 06 质检报告。
- 镜头重构不能偷换源文关键事实、因果、真实动作顺序、人物选择/代价及用户锁定的信息揭示；实质改写须明示并取得授权。
