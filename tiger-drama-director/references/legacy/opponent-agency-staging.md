# 对手自主决策与智斗镜头验收（V18）

适用于原剧本已有谈判、诈供、威胁、规则博弈、权力逆转等智斗场景。只导演已写出的选择与后果；不得代编剧补充收益、法则、证据或人物决定。若剧情因果未闭合，标记 `WRITER_APPROVAL_REQUIRED` 并反馈01，不通过运镜掩盖。

## 逐场导演检查
1. **三方信息**：分别列主角、对手、观众在每一揭示点已知的事实。镜头中的特写、插入画面、屏幕文字与声音都算信息泄露。尚未揭示的证据不可提前露出。
2. **对手有选择权**：剧本允许核验、拖延、拒绝、撤退、讨价还价时，给对手可观察的判断时刻（视线、停顿、动作、对物证的反应），不能通过剪辑将其塑造成无理由屈服。不得额外发明对手的策略或台词。
3. **威胁与回应的因果**：检查每个镜头的`可见筹码→对手是否可核验→对手已知替代方案→真实反应→结果`。导演镜头可以突出已有证据，不能把未获证实的威胁拍成客观真相。
4. **反转前后镜头**：前置线索应在观众可注意但不必立即理解的时刻出现；揭示镜头必须能追溯到已存在的线索。不得用临时插入的未写证据强行解释。
5. **双层结果**：区分“对手某方案不可行”与“对手接受主角方案”。只有剧本明确写出后者才可把签约、交物、投降等作为已确定结果。否则标 `PROPOSED / WRITER_APPROVAL_REQUIRED`。
6. **可生成性**：微表演优先使用单一可见动作与反应Take；屏幕字、复杂手部、多人同步反应按AI可行性拆分。每个编辑SHOT与生成TAKE分别编号并追踪起止物理状态。

## 对抗微案例
- 监控断电且嫌疑人知情：警察指向摄像头，导演不能插入不存在的录像画面证明诈供成功。预期：阻断虚假证据镜头。
- 对手盗取会亏但可谈判：导演不得将“盗取不划算”的算式直接剪成“必须当场签约”。预期：保留谈判余地或反馈编剧。
- 对手持有替代氧气瓶：导演不得仅靠压迫特写让对手无理由交钥匙。预期：如实表现拒绝或标明需要新增剧情事实。
- 克制的成功：已有规则、线索、证据及选择充分成立时，用一次对手核验和一次签字反应即可完成权力逆转，不因镜头少而扣分。

## 交付前门禁
每个重大智斗结果核对`原剧本锚点 / 观众可见证据 / 对手可行替代 / 反应镜头 / 结果授权 / TAKE映射`。任一关键剧情结果未获授权，标记`WRITER_APPROVAL_REQUIRED`；不得宣称分镜已可投产。
