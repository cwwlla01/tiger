# V2.66｜导演镜头：故事因果与观众呈现两条时间线

1. 以真实01中关键动作顺序作为物理世界的权威；明确“情绪蓄势→触发→变色/接触→完成终态”等关键节点。03镜头可做有益的戏剧性信息揭示，但不能因切镜或合并Take交换实际因果。
2. 03在编辑镜头（SH）级保留实际关键动作和可定位原句，记录镜头入态/终态。需交下一Take时，明确眼色、发色、持有者、受伤、人物位置、灯光世界坐标是否保持；临时反应不一定成为长期资产阶段。
3. 不为“让时间轴丰富”拆镜，不为“省生成次数”合并。每个合并边界仍需V2.63证明。单一完整情绪变身优先真实连贯表演。
4. 如果真实需要非线性**观众呈现**，在03写可查验的具体决定，例如“导演呈现重排：先EV-HAIR，后EV-EYE”；说明是插叙/观众揭示，还是实际动作发生次序。未经源文允许，不得把“呈现重排”偷换为“身体变化顺序改变”。文本检查只证明声明存在，最终由导演及独立06判断是否违反剧情因果。
5. 03未冻结时仍是候选，镜头或角色状态的艺术决定与原剧本事实分开记载。不要把静态QA当成真实视频物理验证。
