# 导演分镜高质量对抗门禁 V2

## 使用时机
关键武戏、智斗、牺牲、人物登场及交付前总审时使用。先验证剧情与空间，再评审美；评分不能覆盖硬失败。以已读剧本为事实，导演创作标 DIRECTOR_DESIGN，实质改戏标 WRITER_APPROVAL_REQUIRED。

## 六个必须举证的门禁
1. **无声可读测试**：暂时静音，只看相邻镜头，能否辨认行动目标、谁占上风、结果因何发生？若不能，先修空间/动作/反应，不增加炫光。
2. **视线与空间反证**：标注人物位置、进出口、运动方向、视线轴、道具持有者；对连续两个Take核对末态→初态。无法到达、道具瞬移、伤口消失均硬失败。
3. **信息时序反证**：观众、主角、对手各自知道什么；提前揭露谜底或遗漏决定性线索均失败。可以保留悬念，但不能以含混代替信息控制。
4. **华丽镜头删除测试**：删除慢动作、环绕、特效后，剧情是否更清晰且情绪不减？若是，删除该镜头；L2仅在不可替代的命运转折使用。
5. **表演可见性测试**：「震撼、悲痛、压迫」必须落到具体动作、构图、声音或他人反应；抽象形容词不能作为镜头指令。
6. **AI生成风险反证**：多人物交叉、精细手部接触、连续变形、多个独立构图是否挤在一个Take？提供拆分/遮挡/剪辑替代，并注明起止状态及代价。静态审核不代表模型成功。

## 两方案竞争
对重点场景内部比较 A（最清楚的因果与地理）与 B（更强情绪/形式）。只有 B 在不损害事实、空间和AI可行性时才选择；允许 A 获胜。输出只保留获胜方案和简短取舍理由，不强制多交付物。

## 对抗性微案例（非权威剧本）
- **假动作大片**：三人互换位置、道具从右手跳左手，靠特效遮盖。预期：FAIL，空间/接触不连续。
- **假智斗**：观众在谜底揭晓前看到关键机关全貌。预期：FAIL，提前泄密。
- **假悲壮**：陌生人死亡配90秒慢镜头却没有关系证据。预期：压缩形式，反馈编剧铺垫不足。
- **克制成功**：固定机位、一个视线反应、一声环境音完成权力逆转。预期：PASS，不因镜头简单降级。

## 验收记录
每个硬失败记录 `剧本锚点 / 镜头或Take / 失败原因 / 最小修复 / 复核证据 / 状态`。未获授权的情节增写不得偷偷变成导演设计；重大剧情缺口退回01，资产身份缺口交02，跨文件验收交06。


## V5 导演补动作与镜头/Take双账本
- 剧本未明确胜负、持有者或关键动作时，导演可提供拍摄备选，但必须逐项标 `PROPOSED / WRITER_APPROVAL_REQUIRED`，不得写成已批准的剧情事实。未知结果可保持开放，避免替编剧做决定。
- 每个编辑镜头编号 `SHOT` 与实际视频生成 `TAKE` 单独记录；同一编辑镜头拆成多个生成Take时，列出映射、各自生成时长、保留时长和剪辑衔接，不得声称镜头数等于Take数。
- 对道具状态执行逐镜验证：位置、接触者、持有者、移动路径、画面证据；若状态转移来自未获批准的导演补充动作，连续性账本标为条件成立，不视为权威状态。
