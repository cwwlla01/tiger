# 危险、怪物与悬念显露

威胁显露阶梯：(1) 故事内声音，(2) 环境证据，(3) 角色感知/反应，(4) 实体局部，(5) 实体全貌。只选择来源支持的层级；不得仅凭无法解释的声音暗示怪物已经得到确认。

每项威胁都记录 `source_proof`、`visibility_allowed`、`audience_question`、`asset_status`、`action_complexity`、`fallback`。完整显露怪物需要稳定的身份资产和明确的空间关系；否则应标记为资产阻断，不得暗中替换正典设定。

威胁来自环境时，呈现可通行的空间、危险如何触发及其后果。威胁来自社会关系时，呈现谁知道规则、谁作出决定、谁承担代价。威胁来自资源时，只有来源有依据才追踪前后数量；绝不虚构 UI 计数器。

声音桥接可以暗示画外动作，但不能替代剧情明确要求的视觉证据。只有在因果链仍清晰可懂时才使用插入镜头。
