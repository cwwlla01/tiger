# 03 导演分镜阶段：职责与产出

## 阶段定位

03 的工作不是把剧本改写成一张更细的事件清单，而是创作一套能把故事转化为观众视听体验的导演方案。先做导演判断，再做制作交接。分镜应体现一位导演对场次目标、观众注意力、空间、表演、镜头和节奏的明确选择。

分镜可以重构原文的呈现方式，不必照搬原文逐句、逐动作、逐地点描写；只要故事事实、因果、人物选择与代价、真实动作顺序、关键状态变化和用户锁定的信息揭示不被偷换。可合并、拆分、延迟呈现或改用画外声/反应/结果镜头，但每种重构都要服务于戏剧表达和可读性。实质改变剧情事实或戏剧节拍时，标出改变与影响并等待相应授权。

## 阶段边界

| 阶段 | 对该阶段负责的内容 |
| --- | --- |
| 01 剧本 | 事件、因果、对白、人物选择/代价、规则和状态变化等故事正典。 |
| 02 资产 | 03 前按本集清单查询/初始化身份与造型记录，管理 Asset/Stage/Look ID、历史匹配、来源、版本及批准状态；03 后只处理新增造型或冲突的定向增量。 |
| 03 导演分镜 | 在可信造型上下文中自主作导演选择：场次戏剧解释；观众视点与信息路径；空间和人物调度；表演；构图、景别、机位、镜头运动或固定选择；镜头递进、剪辑关系、声画组织、节奏；动作可读性，以及何时/如何让造型进入观众视野。 |
| 04 静帧提示词 | 将 03 已确定的关键画面意图编写成图片生成提示词；不代替 03 设计镜头，也不擅自改变画面意图。 |
| 05 视频提示词 | 将已确认分镜编译为模型可用的视频提示词；不重新导演或改变镜头的戏剧目的、动作因果和边界。 |
| 06 独立质检 | 按证据独立检查各阶段一致性和制作条件；不是 03 正文，也不代替导演创作。 |

## 导演从场次到镜头

1. **抓场次**：明确场次要达成什么、阻力是什么、发生何种转折/兑现，以及观众在开始、过程和结束时知道或感受到什么。抓住需要保留的事实和戏剧功能，不把内部事件台账全部交付。
2. **提出视听构想**：选定一个能组织本场的主要观看策略（例如受限视野、空间距离、人物视线、遮挡、尺度变化、动作失败与再尝试、声源位置、静与动的反差）。策略必须对应本场戏剧问题；不为展示“电影感”堆术语、特效或运镜。
3. **组织舞台**：只将会影响观众理解、动作可信度或镜间衔接的空间信息具体化。为复杂空间给出简图或锚点、位置、路径、视线/轴线及摄影机工作侧；简单场景不强制制图。未知事实可用不冲突的导演假设补足并标明，不伪装成剧本或资产设定。
4. **编排表演和镜头递进**：以注意力、行为变化和戏剧节拍来决定镜头，而不是按文字行数切镜。明确人物做了什么、为何被观众看见、动作/反应如何改变局面。镜头可长可短、固定或运动；每镜有实际职责，多个镜头应形成递进、对照、揭示、停顿或兑现，而非重复同一信息。
5. **最后验证制作条件**：检查状态连续、必要资产、动作可读性和 AI 风险。遇到风险时先保住戏剧表达，再用景别、遮挡、机位、动作拆解或剪辑作最小调整。模型能力是实现边界，不是创作起点。

### 表现层缺口由导演主动补桥

- 剧本负责核心事件、因果、人物选择/代价和状态结果；不负责列齐每一步身体动作、手部交接、道具离位和摄影机可见性。此类常规表现层空白，默认由导演做一个最小可信的 `DIRECTOR_DESIGN`，无需因“原文没写”退回编剧。
- 对机械或空间关系，优先选择观众容易读懂、生成负担低且不改后续状态的动作桥；只记录会影响下镜/跨集的状态（如道具仍完整、仍由谁持有、是否继续承力）。不为观众不需要的信息额外制造解释镜头。
- 只有当所有合理桥接都会改变人物动机、事件结果、关键因果、规则或跨集连续性，才判定为剧本缺口并提出编剧确认。场景尺寸和模型能力未验证时，先给可执行方案，标明局部验证项；不得用未验证替代“导演选择”。
- “观众不会较真”不能作为省略核心动作的理由；但不重要的微观物理细节可通过遮挡、剪辑、景别、声音或画外动作处理，只要关键事件与因果清楚。

## 镜头卡应传达什么

每镜只写足以令导演意图明确、令制作可执行的内容；按需选字段，不要求每镜填满同一套表格：

- **观看任务**：本镜观众需要注意什么、获得/暂时缺少什么信息，或情绪如何变化。
- **画面组织**：主要主体和视觉层次、画面位置/视线、景别、机位/角度/高度；固定或运动，以及这样选择的作用。
- **调度与表演**：人物起始关系、关键动作/犹豫/选择/反应和结束状态；只有会影响可读性/连续性的动作细节才展开。
- **声画与剪辑**：必要的对白/现场声/画外声/音乐意图，切入切出或与前后镜头的视觉、声音衔接。
- **源文锚点与边界**：简明指出对应的源事件/事实；对重构、合并、拆分、画外呈现等关键决定说明意图。只有涉及正典改变才标记需编剧授权。
- **制作约束（按需）**：相关资产 ID/状态、首帧/尾帧/关键帧意图、Take 映射、风险与回退。简单、低风险镜头不必重复列全局连续性，也不必强制设计静帧。

镜头卡不是 04/05 提示词。以可读的导演语言写清画面与行为，不写模型关键词串、反向提示词、供应商参数或图片内容清单。若一个判断已在场次方案或空间图中成立，镜头卡只记录镜头特有的变化。

## 输出前的导演自审

- 这场有清楚的戏剧构想吗？观众的注意力和情绪是否被有意组织？
- 镜头之间是否产生推进、反差、信息变化或必要停顿；删掉一镜会损失什么？
- 关键人物选择、动作因果、失败/代价与结果是否被看懂，而非只在台词或资产备注中出现？
- 空间、人物位置、视线与摄影机是否让观众知道动作如何发生？
- 资产、连续性、AI 风险等备注是否为创作服务且足够精简，而非淹没导演方案？
- 分镜是否仍只是换词复述剧本？若是，回到场次层重新作导演选择。
