# 03-专业导演分镜｜HELDOUT-260｜B 主观遮挡方案（选中）
来源：助手独立构造的陌生测试场景；非用户权威剧本、非正式项目；导演提案。15秒，4编辑镜头，4独立Take，画幅16:9，精品3D国漫CG。文本级评估，未生成视频。

## 叙事意图与空间
女孩在近侧站台，红伞始终在轨道对面的站台；摄影轴线固定为近侧朝对侧。列车从两站台之间通过，先遮住红伞，再驶离。观众和女孩同时失去视觉证据。雨夜由站外雨幕、衣物潮气和冷反光表现；不凭空让地下站台下雨。伞下有无人、为何消失均不解释。

## 四镜头
1. **S01 0–3秒 / T01**：女孩侧后方中景，近侧站台占前景；她的视线越过轨道停住。摄影机轻微跟随视线右移，画面尽头出现对面站台的一点红色。功能：由人物发现引导观众，而非直接展示谜底。光源：冷色站台顶灯。声音：远处列车接近。状态：女孩未移动位置。
2. **S02 3–6秒 / T02**：女孩视线方向的中远景，撑开的红伞独立位于对面站台一盏灯下，伞沿遮住内部；固定机位，保留两侧可辨认的柱子作为空间参照。功能：明确红伞存在和位置。声音：列车轮轨声渐近。禁止：露出持伞者、伞移动。
3. **S03 6–11秒 / T03**：保持S02机位与构图，列车从近侧轨道方向横穿画面，逐步完全遮挡红伞；不在列车经过期间剪切到伞后。功能：用物理遮挡创造唯一消失窗口。声音：轮轨声掩盖一切细节。末态：列车尾部即将出画。风险：多主体遮挡及列车运动；回退：实拍式列车遮挡层与固定站台底板后期合成。
4. **S04 11–15秒 / T04**：与S02完全匹配的对面站台固定构图，列车尾部离开后，同一柱间位置空无红伞。保持2秒空镜，不加怪物、脚步或解释；末尾切黑。功能：让观众自行确认失踪。声音：列车远去，环境声重新浮现。风险：跨镜头精确匹配；回退：同一静帧底板制作有伞/无伞两版并合成列车遮挡。

## 资产与帧策略
人物女孩、红伞、近侧/对侧站台、列车均为PROPOSED，无获批母版。T01参考资产可选，T02与T04优先共享固定场景参考；T03使用同场景参考与列车运动分层。没有真实模型能力证明，不强制每Take首帧。站台灯位、柱间关系、红伞消失位置必须在资产阶段锁定。

## 导演自审
原始四个事件全部保留；不增加伞下人物、灵异原因、人物追逐；4段总时长3+3+5+4=15秒。真正高潮落在列车尾部出画后观众发现空位，而非额外惊吓。待验证：站台真实布局、列车方向/遮挡、场景一致性、视频生成能力与成片艺术效果。
