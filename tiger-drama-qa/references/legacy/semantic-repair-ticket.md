# 语义修复工单合同

每张工单必须由来源核验和对应专业审计角色共同确认问题。示例：

```json
{"tickets":[{"id":"P0-001","file":"02-example.md","source_sha256":"<原始文件SHA256>","old":"原文件中唯一出现的错误原句","new":"经生产责任人核对的替代句","source_evidence":"03-专业导演分镜.md T-023B/C 原文位置","rationale":"初始阶段混入后续损坏状态","owner":"资产生产负责人"}]}
```

不得把示例视为真实项目已验证工单。`--write-candidates` 只是生成修复候选副本。需要重新审查并留存审核人、版本、证据与终审结果；不能自行签收。
