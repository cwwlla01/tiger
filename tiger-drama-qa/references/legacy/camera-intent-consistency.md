# 03/04/05 摄影意图一致性审核 V2

审核前读取真实权威03、04、05与可用模型证据；无文件标记 NOT_VERIFIED，不得声称通过。逐镜/Take核对：
1. 03主摄影运动与视角/光学/时间/转场修饰在05完整传递；04仅承载静态帧所需的构图/状态。
2. 03与05的起始机位、路径方向、高度变化、主体画面锚点、速度阶段、焦点、终止构图一致；不能把滑动变焦偷换成普通推镜，把子弹时间偷换成慢动作。
3. 镜头轴线、人物视线、屏幕运动方向、道具和身份版本跨镜一致；生成时长与剪辑时长分开。
4. 复杂镜头若拆段，母Take、子段起止状态、后期衔接完整；未经核实不得宣称模型能一次实现。
5. 模型失败回退不得改变导演意图；发生实质变化时标记 `DIRECTOR_REVISION_REQUIRED`，退回03责任方；不可由05自行修改03。
6. 对每项失败记录镜头ID、03依据、04/05实际、严重度、责任Skill、复验结果。仅文本结构通过不代表真实生成视频通过。

## 可选结构化交接检查（V2.1）
当03和05另行提供按 Take 编排的 JSON 摄影交接清单时，可运行 `scripts/audit_camera_contract.py --director-json 03-camera.json --video-json 05-camera.json`。JSON 顶层均为 `{"takes":[...]}`，每条必须含 `take_id`、`camera_primary_id`、`camera_modifier_ids`；按需包含 `start_state`、`end_state`、`screen_axis` 和技法专属字段。脚本检查技法ID、CAM-12/21/22/31的关键运动参数与起止状态是否被保留。该检查**不直接解析 Markdown 03/05**，也不替代人工导演审查、实际视频效果验证；缺少结构化清单时应标记 `NOT_VERIFIED`，不能报自动通过。
