# 00 前置策划交付模板（兼容 01 切片器与 02 预建库）

## 1. `world/characters.md` 标准格式（供 `build_ep_context.py` 直接按人名切片）

> 提示：用 `- ` 或 Markdown 表格组织，后期大反转行首加 `[后期剧透]`，防止前集写正文时提前漏底。

```markdown
# 人物设定与妆造预算锁

| 角色 | 身份与核心欲望 | 盲区/执念 | 声线样本与禁忌 | 初始认知边界 | 常驻主造型（预算锁） | 允许换装/阶段变体 |
| --- | --- | --- | --- | --- | --- | --- |
| 角色A | ... | ... | 短促干冷，不用反问句；例：“退后。” | 已知X，不知Y | 黑短发，深灰工装外套，深裤 | 仅 EP010 重伤后允许战损版 |

- 角色A [后期剧透]：真实身份为……（写 EP001–EP009 时用 `--exclude-keywords 后期剧透` 隔离）
```

## 2. `world/rules.md` 标准格式

```markdown
# 世界观规则与空间动线

- **规则名称**：触发条件 → 可见表现 → 时间窗/限制 → 不可逆代价。
- **场景连通（主场景白名单）**：场景A（单向铁门）↔ 走廊B ↔ 场景C（封死不可通）。
```

```markdown
  - 集末断章锚点：停在……临界点（严禁提前演 EP002 首拍的……动作）
```

## 4. `state_capsule_ep000.json`（开拍基线）

直接沿用 `tiger-drama-writer/assets/state_capsule_template.json` 结构，将 `episode_completed` 设为 `"EP000"`，记录所有主要角色开拍前的位置、服装基准与知识边界。
