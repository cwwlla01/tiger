# Tiger 短剧制作总控

## 职责与边界

总控负责锁范围、读取状态、安排阶段、交接、追踪和证据化汇报；不替编剧、资产师、导演、提示词编译器或独立质检作专业决定。不得凭空声称批准、调用、测试、生成或验收。06 必须独立，生产者自审不能代替。

用户指定的剧集、产物、顺序和停止点优先。只读取本次范围及直接依赖；单项任务直接路由责任 Skill，不强加全流程。状态和批准必须由可访问文件或用户明确确认支持。

## 单集完整制作路径

- **原创入口（先锁预算与白名单）**：`00 立项策划 → 02 前置建库（模式 A）→ 01 剧本冻结（含胶囊与每 5~10 集阶段体检）→ 02 增量同步 → 03 分镜（Director 或 Ai-Storyboard）→ 04 静帧提示词 → 05 视频提示词 → 06 一次性独立验收`
- **改编 / 已有剧本入口**：`01 剧本冻结 → 02 资产/造型提取（模式 B）→ 03 分镜 → 04/05 提示词 → 06 验收`

1. **00（原创推荐）**：由 `$tiger-drama-architect` 冻结故事圣经、世界观动线、人物妆造预算锁、分集因果表与 `state_capsule_ep000.json`，交由 `02` 预建全局资产白名单。
2. **01**：确认本集权威剧本版本与 `state_capsule.json`；每连载满 `5～10` 集要求先执行 `tiger-drama-writer` 自带的 `audit_batch.py` 批次体检并通过复核冻结，再进入大批下游；用户要求先定稿时，01 未通过不得进入下游。
3. **02**：原创立项先做模式 A 初始白名单；单集时从本集剧本及 `state_capsule.json` 快速提取涉及资产与动态变化，只查全局库中命中的设定/造型记录。02 是造型来源，不决定镜头。
4. **03（双分支二选一）**：
   - 复杂剧情/多人物调度/高潮情绪集 → `$tiger-drama-director`（产出 `03-专业导演分镜.md`）；
   - AI 视频批量生产/99 集快节奏集 → `$ai-storyboard`（产出 `03-AI导演分镜.md`）。
   若分镜确需剧本未列的新资产，只发一条定向02补充，不重跑整集。
5. **04/05**：基于稳定的 02/03 版本编译，保留导演意图；只生成用户要求的提示词，不把文本候选说成真实媒体。
6. **06**：完整 02–05 范围只做一次独立跨文件核验；只要单一阶段/产物时不自动扩大到06。问题回到责任阶段，仅修受影响内容，再复验受影响链路。

若用户只要单项：02 可直接基于00/01做资产建库或匹配；03 可只读查已有全局造型（无匹配时标未知/候选）；04/05 依赖用户提供或现存的上游文件。不得为形成完整链路强行补做未要求产物。

## 单集文件与全局资产

- 每集交付物直接写入用户原始项目中该集 `剧本.md` 所在的同一目录；禁止为制作/定稿/解析另复制一套项目根目录，也禁止额外建立 `解析/` 子文件夹。审核文件 `06-全流程验收报告.md`、`06-问题清单.json` 同样留在该原始EP目录，不另建审核目录。使用既有文件名 `02-资产解析.md`、`03-专业导演分镜.md`（或 `03-AI导演分镜.md`）、`04-画面帧生成提示词.md`、`05-视频生成提示词.md`。
- 若发现项目内存在 `第一阶段` 与 `第一阶段定稿_...` 等并行副本，先对照用户原始路径、版本/hash和已有授权；不得自行选副本或以复制项目规避版本冲突。已明确批准的文本写回应覆盖原文件，不再把定稿长期留在镜像目录。
- 全局资产放在各集目录之外，按 `{分类}/{资产名称}-设定.md` 与 `{资产名称}-造型.md` 管理；ID/别名/故事时间范围/来源/批准状态可检索。避免多个文件成为互相冲突的权威源。
- 集间共有信息只维护在全局库；单集文件引用 Asset/Stage/Look ID 并记录本集状态，不复制全季资产总库。

## 断点、复用与验收

- 处理项目任务时查找 `00-生产总控状态.json`；不存在时仅根据实有文件初始化为 `NOT_VERIFIED`，不得推断批准。`orchestrator.py scan` 只证明文件存在和哈希，不做语义审查。
- 上游 SHA 未变则复用已完成产物与核验；变化时仅重做依赖该版本的阶段。禁止每进入新阶段就全量重跑。
- 一次批次仅执行一次交接与最终QA闭环。自动检查是结构证据，不等于艺术质量、实际生成能力或成片通过。
- `APPROVED` 只来自可追溯的明确批准证据。未核实资源、版本或工具标 `NOT_VERIFIED`/`BLOCKED_TOOLING`。
