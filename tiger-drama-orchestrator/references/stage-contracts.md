# Tiger 阶段合同（V3 双入口流程）

| 阶段 | 输入 | 输出 | 作用与门禁 |
| --- | --- | --- | --- |
| 00 前置策划（原创入口） | 一句话灵感/梗概 | `world/rules.md`、`world/characters.md`、`outline/season_outline.md`、`state_capsule_ep000.json` | 冻结世界观规则、声线与常驻妆造预算锁；小说改编可跳过。 |
| 02 前置建库（原创模式 A） | 00 策划档案与 `state_capsule_ep000.json` | 全局资产设定/造型白名单 | 锁定初始 `CHAR/PROP/SCENE/MONSTER` ID 与允许换装节点，约束 01 不私增服装/场景。 |
| 01 编剧 | 00 策划+白名单 或 原著小说 | 本集定稿 `剧本.md` + `state_capsule.json` | 锁定版本；每 5～10 集用 `audit_batch.py` 体检冻结后再开下一批。 |
| 02 资产增量/提取（模式 B） | 01、`state_capsule.json` 与全局库 | 同集目录 `02-资产解析.md`；更新全局库增量 | 提取或增量同步本集资产与污损/伤势动态；不得导演化场面。 |
| 03 导演 / AI分镜（二选一） | 01、02 本集造型/状态映射 | `03-专业导演分镜.md`（Director）或 `03-AI导演分镜.md`（Ai-Storyboard） | 复杂戏剧用 Director，批量快产用 Ai-Storyboard；不得改写正典或批准资产。 |
| 02 定向补充（仅触发） | 03 中有理由的新资产/新造型提案 | 对应全局文件和本集02映射的增量更新 | 只追加缺项或映射；不重新解析全剧、不重写不受影响镜头。 |
| 04 静帧 | 稳定的 03 与 02 造型引用；仅选定的关键画面 | 同集目录 `04-画面帧生成提示词.md` | 单帧状态忠实承接导演选择；不擅自改构图/造型，不强制每镜生帧。 |
| 05 视频 | 稳定的 03、04 及02映射 | 同集目录 `05-视频生成提示词.md` | 逐需编译动作、声音、镜头边界与终态；未知平台能力明示，提示词不等于已生成媒体。 |
| 06 QA | 本次范围内的 01–05 和可用批准/生成证据 | 同集目录 `06-全流程验收报告.md` + `06-问题清单.json` | 按本次验收范围独立检查；真实图片/视频缺失时相应媒体门禁为 `NOT_VERIFIED`。 |

## 依赖方向

完整候选生产依赖为：`01 → 02造型匹配 → 03 → 04/05 → 06`。02 在03之前只提供可见资产的身份和造型来源；03 对造型的戏剧使用拥有导演权。03 如提出新的可复用造型，只触发一次02定向增量，不构成02↔03全量循环。

候选产物可供下游候选工作使用，但不得冒充正式批准。分清 `ready_for_candidate` 与 `ready_for_authoritative_handoff`；后者要求适用上游均有明确批准证据。06只有用户要求验收/总控流程明确要求时才运行，不强加给单项产物请求。

04/05 可由同一提示词 Skill 连续执行，但两份文件分开。若01哈希未变，不重做01；02新增造型只使引用它的镜头/静帧/视频失效，不使整集所有产物自动失效。
