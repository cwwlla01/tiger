# V2.62 | Seedance 2 Fast 最终交付与失败时封闭路由

用户要求 Seedance 2 Fast 可执行提示词时，面向用户的主要交付物是05中完整可复制的模型文本。按以下顺序协调：来源 → 内部导演03 → 仅在确有需要时进行资产/参考素材路由 → 可选静帧04 → 视频05 → 独立06语义和结构审查 → 制作方修复 → 独立复验。默认不要把03或时间节拍表作为最终交付物展示。用户明确要求审查03本身时，仍应提供完整03。

发布05前，要求完成场景专属覆盖图：源文节拍→SH→T→生成时刻→剪辑保留区间→绝对剪辑时点→可见兑现截止点。要求灯光、摄影、表演/物理和摄影机轴线保持连续；为适应 AI 可行性，一个 SH 可以对应多个 T；在模型支持多镜头的工作流中，一个 T 也可包含多个 SH。无须追求最多剪切点。运行两项 V2.60 检查后进行语义审查；制作方先在自身职责内修复，再由独立方复核。只有核实后最终报告才能标为 TEXT_READY；未经批准的分镜应标为 CANDIDATE；没有证据时不得声称已上传源资产或生成视频。模型 UI 能力不确定性应与文本可行性分开。

不得把06结构检查升级成视频验收，也不得让同一作者冒充另一位真实独立审核者。不要把示例性15秒场景包装成已冻结的真实项目。处理项目时，归档实际核实的文件和哈希；不要只依赖对话中声称此前已安装过压缩包。
