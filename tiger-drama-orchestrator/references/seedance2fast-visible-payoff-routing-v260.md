# V2.60｜继续任务的最短生产闭环

收到“继续”且上一正式交付为 Seedance 2 Fast 六题05候选时，先读取真实存在的V2.59包及其六份提示词和来源清单，不可仅以历史声称的测试成绩作为证据；有明确新版本产出才升级。默认用户要的是**可复制05**, 不是内部的03时间线或QA报告。

- 实际总控顺序：读取原始来源 → 03导演候选/权威 → 智能合并Take → 05按SH秒级时间轴 → 每个SH关键事件的可见画面时间点 → 实际剪辑截取边界 → 生产静态检查 → QA独立静态检查 → 人工源故事与电影表达审查 → 打包。
- 生产脚本路径为 `tiger-video-prompt/scripts/audit_seedance2fast_v260.py`，QA脚本路径为 `tiger-drama-qa/scripts/audit_seedance2fast_v260_independent.py`；二者均要求用已读取的源镜头ID运行。不能单凭源镜头数量与屏幕切点判定高潮兑现。
- 04可根据身份和关键地形复用需求额外提供纯静态参考图提示词，若图像未真实制作，不能标`已绑定`，也不能用无效的 `@图片N` 占位注入实际05复制块。
- 真实生成时长按已核实服务端限制与用户即梦界面选项区分。单个Take失败可局部拆镜重生成，不把已成功段全部推倒。
- 六题只是用户上下文提供的短剧情练习，若没有正式冻结01/03、真实批准资产和出片，只能标 `CANDIDATE/TEXT_ONLY`；交付通知里只给事实、遗留的实机依赖与文件链接，不用虚高分数或笼统PASS。

- 对每个Take或POST编写绝对成片区间，与视频内部以零起点的时间轴区分。完整15秒成片按本区间拼接，所有关键画面必须在源Take已保留窗口内。
