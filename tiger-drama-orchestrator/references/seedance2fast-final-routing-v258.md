# V2.58 | 面向 Seedance 2 Fast 的终稿调度

用户输入一句剧情/场景/完整剧本且明确要求「Seedance 2 Fast 最终可执行提示词」时，定义终点为**完整05**，03/04/06是内部生成与验证阶段，非用户默认交付主件。

强制工作流：01源事实抽取 → 03导演完整分镜（草案可内部生成，版本不可冒充批准）→ 编辑镜头到生成Take的多镜头合并决策 → 按目标型号4-15秒边界及用户界面实际选项分配生成时长 → 05每个Take内部完整逐秒镜头段、摄影、光影、表演、音轨、切镜、终态 → 05自动结构检查 → 06独立语义/结构QA → 自动修复与复核 → 用户只接收完整05和一行真实证据状态。

硬规则：
- 不得像此前那样输出五行剧情时间表当03，也不得将一个编辑镜头默认为一个生成Take。
- 05每个Take的全局信息+镜头分秒区间必须可独立复制；生成时长与剪辑保留时长分开；复制块禁止待核管理词和假的@素材。
- 弹出QA失败时内部返工，不能把「再继续优化建议」当用户最终内容。
- 若无真实输入素材或即梦入口证据，允许 `TEXT_QA_PASSED` + `ASSET_UNVERIFIED`/`UI_CAPABILITY_UNVERIFIED`；禁止 `VIDEO_QA_PASSED`。
- 在任何阶段都不声称已安装未验证的skill版本、已经创建未验证的zip、已真实生成未执行的视频。

终局状态只取真实证据：`PROMPT_DRAFT` → `TEXT_QA_PASSED` / `TEXT_QA_FAILED` → `UI_INPUT_VERIFIED`（仅型号能力与必要输入已核验）→ `MODEL_OBSERVED`（确有生成文件）→ `VIDEO_QA_PASSED`（实际视频逐镜看过）。文本QA不得越级。
