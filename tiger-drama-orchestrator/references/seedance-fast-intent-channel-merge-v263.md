阶段审查应区分用户请求意图、场景专属时长、完整03、完整05、真实上传的参考素材和实际渲染视频。不得把 JSON 字段检查成功说成艺术 QA 或 UI 能力证明。用户应收到一个完整连贯的交付物；管理材料仅在用户要求时才对外提供，否则留在内部。
