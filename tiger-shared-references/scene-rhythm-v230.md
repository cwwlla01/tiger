# V2.30 场次级镜头组合与情绪曲线合同

## 核心原则
以戏剧意图统领镜头组：镜头之间形成因果、注意力转移和情绪递进；技法只是实现方式。先定义场次目标，再决定镜头数和运镜。不得为了填满镜头列表而机械切镜。

## 最小工作流
1. 从01剧本提取每场 `scene_id`、`source_beat_ids`、人物目标、冲突变化、不可提前揭示的信息、场次终态；缺失来源标 `SOURCE_UNRESOLVED`。
2. 给每场选一条可验证的情绪轨迹：`SETUP -> PRESSURE -> TURN -> PAYOFF`，不要求每场四段齐全；每段须对应真实剧情节拍，禁止无来源强行制造高潮。
3. 每个编辑镜头明确 `shot_id`、`scene_id`、`source_beat_ids`、`dramatic_function`、`audience_knowledge_before/after`、`attention_target`、`camera_choice`、`entry_state`、`exit_state`、`cut_reason`。静止与停顿是正当选择。
4. 相邻镜头逐对检查：注意力焦点是否有理由改变、动作/道具/轴线是否连续、是否存在重复信息。能在一镜内更清楚完成的动作不要机械拆镜；必要的反应镜头不得因省成本删除。
5. 对高潮/反转：标记 `reveal_beat_id` 和 `reveal_shot_id`，确保前镜不提前泄露，后镜承接人物反应与后果。
6. 以“观众理解和情绪效果”为先，AI 可执行性为约束；复杂复合运镜拆 Take 不等于新增编辑镜头。不能证明效果提升时保留人工审美复核标记。

## 自检与降级
- 镜头功能重复且无新增信息：先合并或改为停顿，除非表演/声音形成必要的张力。
- 连续三个镜头均为运动镜头：检查是否因炫技而缺少节奏对比；不是一律禁止。
- 关键反转无前置线索或人物反应：退回导演补充源内可支持的叙事表达，不新增剧本事件。
- 输出03母版中的场次级节奏摘要，具体镜头字段尽量复用既有格式，不强制另产 JSON 文件。
