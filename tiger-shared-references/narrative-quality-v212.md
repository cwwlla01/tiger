# V2.12 叙事镜头决策（创作层）

## 每场必须先回答的三个问题
1. 观众此刻知道什么、误以为什么、下一秒应该发现什么？必须以源剧本为证据，不得新增规则真相。
2. 本场谁做选择、代价是什么？镜头优先拍到人物可见的决定与后果，而非单纯氛围。
3. 哪个动作/声音是不可错过的叙事锚点？指定一个明确的画面或声音证据，其他装饰从简。

## 自主选镜：三选一而非技法堆叠
- **观察型**：固定/克制运动，保留空间证据；适用于观众需要核对动作、道具和规则。
- **主观型**：POV、受限遮挡或延迟揭示；适用于角色知识与观众知识需要同步。
- **对抗型**：交叉视线、反应、位置变化；适用于人物选择、威胁逼近、因果反转。
每场先比较至少两条策略，选择一条主策略。只有剧情信息收益明确，才使用复杂运镜；无收益选固定。

## 节奏与表演
- 逐场记录 `setup → tension → decision → payoff`；可省略不适用阶段，但不得用空镜代替必要剧情。
- 为核心人物写一个可拍的行为细节（眼神、手部停顿、呼吸等），不得用“非常害怕”等抽象情绪代替。
- 重要信息只能在其源事件发生后被画面/声音揭示；黑场后的声音不可提前在画面内出现。
- 画幅内看见物体不等于观众能识别：关键线索须有景别/停留/声响或剪辑补偿。
- 每场最多一个主视觉母题；若有第二母题，说明其与人物决定的因果关系。

## 产出和自审
03中每场简写 `观众知识变化 / 人物选择 / 视觉锚点 / 主策略 / 表演证据 / 节奏转折`，无需新增管理长表。自审以反事实提问：删掉该镜头是否丢失信息、情绪或因果？若无则合并或删除。审美判断不得伪装成自动化硬规则。
