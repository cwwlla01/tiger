# V2.10 以 Skill 为产品的优化闭环

## 核心目标与边界
- 项目试验仅用于暴露可复用的 Skill 缺陷。不得将连续多轮单个场景几何调参当作 Skill 升级。
- 每次优化必须产出：缺陷陈述、通用规则变更、至少一个正例和反例、可重复回归证据、版本变更记录。没有规则或代码变更，不宣称 Skill 升级。
- 先验证来源与制作风险。模拟几何结果仅标记 `SIMULATED`，真实资产/生成视频未提供则标记 `NOT_VERIFIED`；不能把模拟通过升级为生产验收。

## 预演停止规则
- 默认每个争议镜头最多一轮简化几何检查和一轮针对性修正；之后必须选择：A 改导演调度，B 降低镜头复杂度/增加插入镜头，C 标记资产阻断并移交。禁止无新增权威资产的无限参数扫描。
- 只有确实影响剧情因果、空间轴线、关键物证可读性、光源物理一致性的镜头才启动几何检查。普通镜头不强制坐标化。
- 当关键信息可通过特写、音效、反应镜头或剪辑桥接更可靠表达时，优先提出低风险可拍方案，而非追求模拟参数的最优数值。

## 回归与证据分层
- `RULE_TESTED`：规则和结构测试通过；`SCENE_SIMULATED`：合成场景验证；`ASSET_VERIFIED`：真实资产证据核验；`MEDIA_VERIFIED`：生成画面逐镜审核。后者不能由前者推断。
- 检查器必须能识别：虚假生产通过宣称、未授权修改03、04/05视觉字段漂移、遗漏黑场音频、无证据却强行增加镜头、无限预演循环。
- 缺陷复盘优先修改 Skill 的决策规则/触发门槛/退回机制；不要把具体测试剧本的人名、戒指、柜体尺寸写进通用 Skill。
