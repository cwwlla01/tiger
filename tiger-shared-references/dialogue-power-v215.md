# V2.15 多人物对手戏导演契约

1. 建立每个角色的 `objective / knowledge_before / knowledge_after / leverage`，每个权力转折必须指向源文事实或标为 `DIRECTOR_DESIGN`。
2. 对每个关键交流事件记录 `beat_id, source_anchor, speaker_id, listener_ids, line_or_silence, eyeline_target, screen_axis, observable_shift`。台词原文不得改写。
3. 先选择信息最清楚的覆盖方案，再决定正反打、双人中景、反应特写或离屏声音。沉默不是空镜，需有可见反应或声音动机。
4. 角色换位、越轴或权力关系变化需明确触发动作；空间不足则选择固定双人镜头或反应插入，不强行越轴。
5. 03定义事件顺序和信息边界；04只选择静态时点；05保留动作/台词/反应因果，不擅自重导演。
