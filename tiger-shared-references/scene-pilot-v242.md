# V2.42 冻结场次双稿试运行（非历史版本 A/B）

## 目的与证据等级
本版附带一个固定剧本、两套**示范性独立分镜草案**和结构化对照。两套草案仅作为评估流程的试运行素材，**不代表 V2.38 / V2.39 Skill 实际独立执行结果**。不可将草案优劣推论为 Skill 版本优劣。

## 执行规则
1. 先冻结原文与逐项 `beat_id`，任何镜头均必须标注来源；不得增设怪物、危险、对白或剧情结局。
2. 对同一场戏分别提出以连续表演为主、以信息揭示为主的可执行方案；每案均应公平、可拍、可独立成立，不以稻草人方案充数。
3. 每镜记录 `shot_id`、`beat_ids`、`dramatic_function`、`editorial_reason`、`duration_s`、`camera`、`sound`；没有独立价值的镜头合并或删除，必要停顿不得因零对白被删。
4. 两案不强制镜头数不同；评估优先看剧情完整、表演可信、观众知情差、节奏、空间轴线、生成可行性。
5. 默认交付最终选定的 03；只有明确要求对照实验才交付双案及审计记录。
6. 真正的版本 A/B 需要分别运行冻结的 Skill 包、保存 run_id、Skill 包哈希、原始输出哈希和独立盲审；本示范不能替代。
