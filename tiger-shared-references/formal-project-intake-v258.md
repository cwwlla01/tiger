# V2.58 正式项目准入与证据分级

正式项目验收需要权威剧本、冻结资产、03/04/05、独立06审查及实机证据；不得把自动化结构测试当作画面质量证明。

准入材料：01权威剧本（来源与版本）；02资产清单（人物/场景/道具/怪物及版本）；03导演分镜；04静帧提示词；05视频提示词；06独立QA。

证据等级：SOURCE_VERIFIED、TEXT_AUDITED、ASSET_VERIFIED、MODEL_CAPABILITY_VERIFIED、VIDEO_OBSERVED、PRODUCTION_ACCEPTED。不能跳级。

阻断分级：GLOBAL_SOURCE_BLOCK（权威剧本缺失）、LOCAL_LAYOUT_BLOCK（单镜头空间缺证）、LOCAL_ASSET_BLOCK（镜头资产缺证）、MODEL_TEST_PENDING（实机未做）。不得凭猜测解除阻断。

现有《倒数第三声》仅为原创测试场次，不构成正式项目准入证据。
