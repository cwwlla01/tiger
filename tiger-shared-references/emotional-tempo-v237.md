# V2.37 情绪张力与镜头时序合同

## 总原则
- 戏剧意图主导、电影技法执行；不以镜头更短、切换更快或运镜更复杂作为质量指标。
- 源剧本事件、信息揭示、人物知情状态与因果先于节奏美化。
- 将「编辑镜头时长」与「生成 Take 时长」分开，模型分段不能擅改成片节奏。
- 场次节奏必须允许非单调变化：紧张后的短暂缓和、假安全、突然中断、延迟兑现都可成立；不强制四段式或固定时长。
- 沉默、画外声、反应停顿可承担独立戏剧功能；不得按无对白或低动作量自动删除。

## 可审计的场次节奏字段（仅关键节点填写，不强制每镜重复）
- `beat_id`：剧本来源节拍；`shot_id`：编辑镜头；`take_id`：生成段。
- `tension_intent`：该节点希望观众感到的变化（`BUILD` / `HOLD` / `RELEASE` / `SHOCK` / `RECOVER`），是意图而非可测的真实情绪。
- `attention_target`：观众此刻需要关注的人/物/空间；`knowledge_mode`：`AUDIENCE_AHEAD` / `CHARACTER_AHEAD` / `SYNCHRONIZED` / `UNCHANGED`。
- `edit_duration_s`：建议成片时长，可为区间或 `UNDECIDED`；不得虚构模型生成时长或将估算伪称实测。
- `cut_trigger`：切点依据（表演变化、动作因果、信息揭示、声音桥接或有意保持）；`sound_role`：`DIEGETIC` / `OFFSCREEN` / `SILENCE` / `MUSIC` / `POST_ONLY`。
- `protected_hold`：重要停顿或反应是否需要保护；若是，标注 `hold_reason`，不得用空白填充时长。

## 取舍门禁
- 若缩短或拆分镜头会提前揭示、删除重要反应、破坏动作因果或改变声音桥接，必须回退或升级导演复核。
- `tension_intent` 只是设计意图；未经真实观看和独立评价，不可声称观众紧张度或成片艺术质量已经提高。

## 独立 QA 执行
1. 对照 03 与 04/05 检查节拍覆盖、顺序、切点、保护停顿、声音策略和时长语义。
2. 结构脚本只能发现显式字段漂移，不能从文本自动判定真实情绪效果。
3. 缺少 03 或关键来源时标记 `NOT_VERIFIED`；无人工盲审不能写 `ARTISTIC_PASS`。
4. 只生成问题单和复验要求，不直接修改 03 母版。
